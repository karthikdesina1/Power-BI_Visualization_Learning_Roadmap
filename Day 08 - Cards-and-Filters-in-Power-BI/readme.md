# Power BI - Cards and Filters

## Overview
Cards and Filters are two important concepts in Power BI that help create clear, interactive, and meaningful dashboards.

- **Cards** display important single-value metrics in a simple format.
- **Filters** control which data is shown in the report.

Together, they help users quickly understand KPIs and analyze specific parts of the data.

---

## 1. What are Cards in Power BI?

A **Card visual** is used to show one summarized value.

### Common examples:
- Total Sales
- Total Orders
- Total Profit
- Total Customers
- Average Profit
- Average Order Value

Cards are useful when you want to highlight key business metrics clearly.

### Why use Cards?
- Easy to read
- Good for KPI reporting
- Useful in dashboards
- Helps users focus on important numbers quickly

---

## 2. How Card Visual Works

To create a card:
1. Select the **Card** visual in Power BI.
2. Drag a numeric field into it.
3. Power BI summarizes the field automatically.

### Common summarizations:
- Sum
- Count
- Average
- Minimum
- Maximum

Example:
- Sales → Sum → Total Sales Card
- Order ID → Count → Total Orders Card

---

## 3. What are Filters in Power BI?

Filters are used to control which data appears in a visual, page, or report.

They help users focus only on relevant information.

### Example:
Instead of viewing total sales for all products, a filter can show:
- Sales for only **Technology**
- Sales for only **East Region**
- Sales for only **2026**

---

## 4. Types of Filters in Power BI

### 1. Visual-level Filter
Affects only one visual.

### 2. Page-level Filter
Affects all visuals on the current page.

### 3. Report-level Filter
Affects all pages in the report.

### 4. Slicers
Interactive filters placed directly on the report canvas.

Slicers are commonly used for:
- Date
- Category
- Region
- Customer
- Product

---

## 5. Applying Filters Step by Step

Basic process:
1. Choose the field to filter.
2. Select the values or range.
3. Apply the filter.
4. View the updated report results.

### Example:
If you filter **Category = Technology**, all connected visuals and cards update to show only Technology data.

---

## 6. Using Cards with Filters

Cards become more powerful when combined with filters.

### Example:
Without filter:
- Total Sales = $2,496,320

After filtering Category = Technology:
- Total Sales = Updated filtered value

This allows users to analyze KPIs for specific segments instantly.

### Benefits:
- Interactive reporting
- Better analysis
- Faster decision-making
- Cleaner dashboard design
